# ThunderSWUFE 
是一款面向SWUFE宿舍用户的智能用电管理与分析 Android 应用。灵感来源于大一时的python获取用电量爬虫程序（https://github.com/Kirawii/SWUFEPowerConsum）。系统集成了用电数据采集、余额与用量可视化、智能预测、异常提醒、历史分析和节能建议等多项功能，帮助用户科学用电、避免断电风险、提升用电安全与经济性。解决了易校园查询电量复杂且无法显示趋势的痛点。

主要功能简介：
用电数据自动采集
支持向易校园服务器发送请求，自动获取宿舍最新余额和用电变动数据，数据本地持久化，断网也能访问历史信息。

余额与用量可视化
主界面以折线图直观展示余额变化趋势，支持横向滚动和缩放，帮助用户快速了解近期用电情况。并设置了多种x轴y轴选项，可以自由观测不同数据尺度下的用电趋势。

智能用电预测
内置本地机器学习模型（TensorFlow Lite），基于历史数据预测未来用电趋势，智能预警“几天后将用尽”，并推送通知提醒，防止意外断电。

异常检测与节能建议
自动分析用电数据，检测突变、高用电等异常行为，生成个性化节能建议，帮助用户优化用电习惯。

历史分析与统计
提供详细的用电历史分析，包括总用量、日均用量、最大/最小用量等统计指标，一键导入历史 CSV 数据，便于迁移和对比。

个性化设置与通知管理
支持自定义余额提醒阈值、房间信息、通知开关，保障个性化体验。

后台自动任务
利用 WorkManager 定时后台检测余额和预测用电，确保信息实时、推送及时，无需手动刷新。
